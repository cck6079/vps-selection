## 挑 VPS 商家，先看这四个指标

价格是最不该第一个看的东西。同样标 $10/月，两台机器的实际体验可能差出一个量级。

**线路是决定体验的第一变量。** 面向中国大陆用户的 VPS，走的是普通国际 BGP、还是 CN2 GIA、CMIN2、9929 这类优化线路，晚高峰的表现完全是两回事。普通国际线路在晚八点之后丢包、抖动是常态；优化线路的价值就体现在这个时段。反过来，如果你的访客全在北美或欧洲，花钱买 CN2 GIA 就是纯粹浪费——它的溢价只对大陆方向有意义。

**有没有超售，看的是稳定性的下限。** 很多商家把一个物理核卖给好几个用户，平时看不出问题，一到高峰就集体卡顿。这个指标官方页面不会写，只能靠第三方测评和长期使用者的反馈去侧面判断。

**流量用完之后怎么办，比流量给多少更重要。** 常见做法有三种：直接停机、按 GB 超额收费、降速但继续跑。对跑中转、下载、流媒体这类长期占带宽的场景，第三种（限速不限量）的实用价值远高于多送几百 GB。

**支付方式和退款条款决定了试错成本。** 支持支付宝、PayPal 的商家，对国内用户来说少一道折腾；退款政策则是你买错机房之后唯一的后悔药。这两条在下单页就能看到，花两分钟确认一下，比看十篇测评都实在。

## 下单前必须确认的四件事

1. **库存。** DMIT 的补货节奏不稳定，页面上的套餐可能几小时内售罄，也可能长期缺某一档。你要的那一款不一定现在就有。
2. **平台。** 同一档套餐可能落在 AS3、AN4 或 AN5 平台上，价格差几美元。AN5 的 CPU 更新、更贵；AS3 更便宜，跑建站、代理、流媒体解锁这类场景，日常几乎感知不到差距。
3. **退款条款。** 第三方整理提到 DMIT 的规则大致是：购买后短时间内、流量使用量很小的情况下可申请全额退款，超期后按剩余价值比例处理，续费订单和余额支付通常不适用退款。这类条款官方随时可能调整，**在你付款之前，去官网的退款政策页自己读一遍**，不要依赖任何二手转述。
4. **先月付，再年付。** 年付省下来的钱是实打实的，但前提是你已经确认这台机器的线路在你自己的宽带上跑得动。用一个月测晚高峰，再决定要不要续年付。

**DMIT 支持哪些付款方式？**

**港、美、日三个机房怎么选？**
